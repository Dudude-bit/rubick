# README screenshots

Every image here is an unedited capture of the real app running against the `k3d-k8s-gui-dev`
cluster, built from the merged `main` (K8s GUI 2.0, `cd1834a`). Nothing is mocked, retouched or
composited; crops only remove surrounding chrome. Captured 2026-08-11.

The Rubick rename (`497aa08`) landed after these were taken, but it only changed window titles,
bundle names and doc comments. No product name is visible inside any of these crops, so they still
show the current app. The `k8s-gui-test` namespace and `*.k8s-gui.test` hostnames are cluster
fixture names, not product names.

Prometheus (`172.20.0.2:30090`) and Loki (`172.20.0.2:30310`) were connected and answering, so
every usage chart is real query data over a real range.

## Cluster states created and restored

Only two objects were touched, both load generators the user had parked at zero:

- `deploy/busy-demo` scaled 0 to 1 (then to 2 by `hpa-busy`), restored to 0.
- `deploy/traffic-gen` scaled 0 to 1, restored to 0.

Both are back at `0/0` and their pods are gone. Everything else that appears broken in these
images - `init-demo`, `unready-demo`, the `ghost-traefik` Ingress - was already broken in the
cluster and was left exactly as found.
