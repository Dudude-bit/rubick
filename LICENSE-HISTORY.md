## Why it changed

The permissive licence allowed a closed, rebranded fork to be built on this
work and sold without the source. That is the outcome this project exists
in reaction to, so keeping the door open for it made little sense.

GPLv3 does not forbid forking, and it does not forbid selling. It requires
that whoever distributes a modified version ships its source under the same
terms. Using the application — including inside a company, on any number of
machines — triggers no obligation at all, because that is not distribution.
